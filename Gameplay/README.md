# Export — Live Puzzle

| Thư mục / file | Mục đích |
|----------------|----------|
| **`gameplay/`** | Logic chơi portable (TypeScript) — adapt vào UI khác |
| **`gameplay/INTEGRATION.md`** | Hướng dẫn tích hợp chi tiết |
| **`live-puzzle-ui.html`** | Mockup UI tĩnh (HTML) — tham khảo giao diện |

## Bắt đầu nhanh (gameplay → UI mới)

1. Copy `export/gameplay` vào project đích.
2. `npm install @mediapipe/tasks-vision@^0.10.14`
3. Đọc `gameplay/INTEGRATION.md` và `gameplay/example-solo-loop.ts`.
